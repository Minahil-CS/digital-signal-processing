# 📷 Photo Restoration & Enhancement using Digital Image Processing

An automated Python-based Image Processing project designed to restore degraded, old, and noisy photographs using **OpenCV** and **Digital Signal/Image Processing** techniques.

---

## 🌟 Overview

Old and damaged photographs often suffer from noise, scratches, fading, and contrast degradation. This project applies digital signal and image processing algorithms to enhance image quality, remove noise, and restore details in damaged grayscale and color images.

---

## 🛠️ Key Features

- **Noise Reduction:** Filters out unwanted grain and noise using spatial filtering techniques.
- **Contrast & Brightness Adjustment:** Uses Histogram Equalization to restore faded details.
- **Edge Enhancement & Sharpening:** Sharpens blurred details and enhances structural outlines.
- **Morphological Operations:** Removes minor scratches and imperfections.

---

## 💻 Tech Stack & Tools

- **Language:** Python
- **Libraries:** OpenCV (`cv2`), NumPy, Matplotlib
- **Concepts:** Digital Signal Processing (DSP), Image Restoration, Filtering techniques
